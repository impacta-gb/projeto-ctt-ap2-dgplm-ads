# Introdução ao Go

Go (ou Golang) é uma linguagem de programação criada pelo Google em 2009 com foco em simplicidade, desempenho e concorrência.

A linguagem foi desenvolvida para resolver problemas comuns encontrados em sistemas modernos, como:
- compilação lenta;
- gerenciamento complexo de dependências;
- dificuldade em trabalhar com múltiplas tarefas simultaneamente.

Go é amplamente utilizado em:
- APIs REST;
- microsserviços;
- sistemas distribuídos;
- ferramentas DevOps;
- aplicações em nuvem.

## Principais Características

| Característica | Descrição |
|----------------|-----------|
| Simplicidade | Sintaxe limpa e fácil de aprender |
| Performance | Compilação rápida e execução eficiente |
| Concorrência | Suporte nativo com Goroutines |
| Portabilidade | Funciona em múltiplos sistemas operacionais |
| Gerenciamento de Dependências | Utiliza Go Modules |

## Primeiro Programa em Go

```go
package main

import "fmt"

func main() {
    fmt.Println("Olá, Mundo!")
}
```

## Estrutura Básica

| Elemento | Função |
|----------|--------|
| package main | Define o pacote principal |
| import | Importa bibliotecas |
| func main() | Função principal |
| fmt.Println() | Exibe texto no terminal |

## Vantagens do Go

- Fácil manutenção de código;
- Excelente desempenho;
- Sintaxe objetiva;
- Grande uso no mercado;
- Forte integração com containers e cloud computing.

## Áreas de Uso

Go é utilizado por empresas como:
- Google;
- Docker;
- Kubernetes;
- Uber;
- Twitch.

## Conclusão

Go é uma linguagem moderna, eficiente e bastante utilizada no desenvolvimento de aplicações escaláveis e de alta performance.
